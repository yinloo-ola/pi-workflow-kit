# ADR 0008: Evidence-first requirements

Unknowns that a run can settle are settled by a bounded sketch at design
time. No requirement is marked complete without an evidence pointer paired
with a plain-words line. The human reviews evidence instead of re-doing the
work, because the recorded failure mode (pwk-status) was three post-ship
corrections for facts that were runnable at design time.

Status: accepted (approved as assumption A8 at design time; shipped as
evidence-spine, v2.9.0 — PRD brief, decide-by-experiment tier, probe test,
Evidence rows).
